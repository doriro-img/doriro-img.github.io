# 블로그 작업 저장소 — Doriro

티스토리 **https://heelovee.tistory.com** 운영에 필요한 것을 전부 모아둔 곳.
원고 · 이미지 · 도식 소스 · 생성 도구가 여기 있다. **다른 PC에서도 이것만 받으면 이어서 작업할 수 있다.**

GitHub Pages로 그대로 서비스되므로 이미지는 글에서 절대 주소로 참조한다.
빌드가 없다. **파일을 넣고 푸시하면 그게 곧 배포다.**

```
2026/08/파일.png   →   https://doriro-img.github.io/2026/08/파일.png
```

## 구성

| | |
|---|---|
| [VOICE.md](VOICE.md) | **문체 정본** — 글 79편 전량 정독으로 뽑은 말투. 글 쓰기 전 필독 |
| [STYLE.md](STYLE.md) | **작성 규격** — 제목·구조·이미지 배치·가독성. 새 글은 반드시 이걸 따른다 |
| [IDEAS.md](IDEAS.md) | 글감 대기열 |
| `posts/` | 원고 정본 (티스토리 HTML 모드에 그대로 붙여넣는 형태) |
| `art/` | 설명 도식 소스 (HTML) |
| `2026/08/` | 이미지. 연·월 폴더로 나눈다 |

## 작업 흐름

| 필요한 것 | 명령 | 비고 |
|---|---|---|
| 처음 한 번 | `npm install` | Chrome은 설치돼 있어야 한다 |
| 설명 도식·비교표 | `node make-art.cjs` | `art/*.html` 을 PNG로 |
| 웹페이지 화면 컷 | `node make-shots.cjs` | 공개된 주소를 찍는다. 서버를 띄울 필요 없다 |
| 올리기 | `node push.cjs "설명"` | 1~2분 뒤 주소가 살아난다 |

셋 다 **올해/이번 달 폴더에 자동 저장**된다. 경로를 신경 쓸 필요 없다.

밖에서 만든 이미지(폰 사진·다른 도구 결과물)는 `2026/08/` 에 직접 넣고 푸시하면 된다.
Chrome 위치가 다르면 `CHROME_PATH`, 찍을 사이트는 `SHOT_BASE` 로 지정한다.

## 규칙

- **파일명은 ASCII.** 한글은 주소에서 깨진다 (`push.cjs`가 올리기 전에 막는다)
- **지우거나 이름을 바꾸지 않는다.** 발행된 글이 이 주소를 직접 불러온다.
  깨져도 본인 브라우저 캐시 때문에 **독자한테만 보인다.** 수정은 같은 파일명 덮어쓰기로
- 이미지는 폭 **860~1100px**. 1MB가 넘으면 `push.cjs`가 경고한다
  (폰 사진은 한 장 3~8MB라 그대로 쌓으면 1GB 한도가 금방 찬다)
- 도식은 **밝은 배경**으로 만든다. 티스토리 스킨이 흰 배경이라 어두우면 튄다

## 한도

지금 평균 110KB이므로 약 9,500장, 월 20만 페이지뷰까지 여유가 있다.
