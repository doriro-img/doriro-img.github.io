# 블로그 이미지 저장소

티스토리(heelovee.tistory.com) 글에 넣는 이미지를 모아두는 곳.
GitHub Pages로 그대로 서비스되므로 글에서는 절대 주소로 참조한다.

빌드가 없다. **PNG를 넣고 푸시하면 그게 곧 배포다.**

## 주소 규칙

```
2026/08/파일명.png   →   https://<사이트주소>/2026/08/파일명.png
```

연·월 폴더로 나눈다. 파일명이 겹치지 않고, 나중에 어느 글 이미지인지 찾기 쉽다.

## 규칙

- **파일명은 ASCII.** 한글 파일명은 주소에서 깨지고 도구에 따라 문제를 일으킨다
- **지우거나 이름을 바꾸지 않는다.** 발행된 글이 이 주소를 직접 불러온다.
  수정은 같은 파일명으로 덮어쓴다
- 폭 **860~1100px** 정도로 만든다. 블로그 본문 폭에 맞다
- 앱 화면이 아닌 도식은 `stock-ledger/docs/blog-art/*.html` 에서 만들어 여기로 복사한다

## 올리기

```
node push.cjs "설명"
```

또는 수동으로:

```
git add -A && git commit -m "이미지 추가" && git push
```

푸시하고 1~2분 뒤 주소가 살아난다.
