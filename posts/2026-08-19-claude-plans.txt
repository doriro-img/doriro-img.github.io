<p>클로드(Claude) 요금제 총정리 2026 - 무료·Pro·Max 사용량과 기능 차이 (바이브코딩까지)</p>

<h2>클로드 요금제, 종류가 헷갈리더라고요</h2>

<p>요즘 챗GPT 말고 클로드(Claude)를 쓰는 분들이 많아졌어요. 저도 쓰는데, 막상 유료 결제를 하려니 무료, Pro, Max에 5x니 20x니 종류가 헷갈리더라고요.</p>

<p>그래서 뭐가 어떻게 다른지, 나한테는 뭐가 맞는지 정리해봤어요. 요즘 유행하는 '바이브코딩' 얘기까지 같이요. (2026년 8월 기준이고, 요금이나 정책은 자주 바뀌니 결제 전엔 공식 페이지를 한 번 더 확인하세요.)</p>

<h2>요금제는 크게 4가지예요</h2>

<img src="https://doriro-img.github.io/2026/08/cl01-plans.png" alt="클로드 요금제 무료 Pro 20달러 Max 5x 100달러 20x 200달러 비교" style="max-width:100%;height:auto;" />

<p>무료는 0원인데 하루 사용량 제한이 있는 맛보기용이에요. Pro는 월 20달러(약 2만 8천 원)로 대부분의 기능이 열리는 입문용이고요. 그 위로 Max 5x가 월 100달러, Max 20x가 월 200달러예요.</p>

<p>이름에 붙은 5x, 20x가 핵심인데, 이건 뒤에서 설명할게요.</p>

<h2>돈 내면 뭐가 달라지나요?</h2>

<img src="https://doriro-img.github.io/2026/08/cl02-features.png" alt="클로드 무료 Pro 기능 차이 Opus Projects Claude Code MCP 표" style="max-width:100%;height:auto;" />

<p>무료와 Pro 사이에 큰 벽이 있어요. 최상위 모델인 Opus, 프로젝트 기능, 코딩 도구인 Claude Code, 외부 연동(MCP) 이런 고급 기능은 전부 Pro부터 열려요. 무료로는 못 써요.</p>

<p>여기서 진짜 중요한 포인트가 있어요. Pro든 Max든 '기능'은 똑같아요. Max가 기능을 더 주는 게 아니에요. Max는 Pro의 기능을 그대로 둔 채 '사용량'만 5배, 20배로 늘린 거예요.</p>

<h2>사용량 한도는 어떻게 되나요?</h2>

<img src="https://doriro-img.github.io/2026/08/cl03-usage.png" alt="클로드 사용량 한도 5시간 주간 이중 배수 클로드 코드 웹 공유" style="max-width:100%;height:auto;" />

<p>한도는 두 겹이에요. 하나는 5시간 한도로, 몇 시간 몰아 쓰면 잠깐 쉬어야 하지만 시간이 지나면 리셋돼요. 다른 하나는 주간 한도인데, 이건 일주일 총량이라 시간을 나눠 써도 못 피해요.</p>

<p>그리고 꼭 알아둘 게 있어요. Claude Code, 데스크톱 앱, 웹(claude.ai)을 다 같은 통에서 차감해요. 웹에서 많이 쓰면 그만큼 코드 작업에 쓸 몫이 줄어드는 구조예요. Pro는 이 통이 제일 작고, Max로 갈수록 커지는 거고요.</p>

<h2>그 기능들로 뭘 할 수 있나요? (바이브코딩)</h2>

<img src="https://doriro-img.github.io/2026/08/cl04-cando.png" alt="클로드 기능 활용 Claude Code Artifacts Design Projects MCP 바이브코딩" style="max-width:100%;height:auto;" />

<p>기능 이름만 봐선 감이 안 오죠. Claude Code는 터미널에서 말로 시켜 코드나 자동화를 만들고, Artifacts나 Design은 말로 웹페이지·앱·디자인을 즉석에서 만들어줘요. 프로젝트는 자료를 모아 맥락을 기억시키는 거고, MCP는 깃허브 같은 외부 도구를 연결하는 거예요.</p>

<p>요즘 뜨는 '바이브코딩(Vibe Coding)'이 바로 이거예요. 코딩을 몰라도 말(자연어)로 시켜서 프로그램을 만드는 걸 뜻해요. "이런 앱 만들어줘" 하면 AI가 코드를 짜주는 거죠. Claude Code가 대표 도구고요. 사실 지금 보고 계신 이 블로그 이미지들도 그렇게 만든 거예요.</p>

<h2>나는 뭘 써야 할까요?</h2>

<img src="https://doriro-img.github.io/2026/08/cl05-who.png" alt="클로드 요금제 선택 가이드 무료 Pro Max 추천 대상" style="max-width:100%;height:auto;" />

<p>결국 '얼마나 자주 쓰냐'로 답이 나와요. 가끔 써보거나 챗GPT랑 비교만 할 거면 무료로 충분해요. 매일 일상 업무에 쓰는 1인 사용자라면 Pro가 합리적이고요. 매일 개발이나 대량 작업을 본격적으로 돌린다면 Max 5x, 하루 종일 붙어 쓰는 헤비 유저라면 Max 20x예요.</p>

<p>부담 없는 건, 플랜을 바꿔도 대화 내역이나 설정은 그대로 유지된다는 거예요. 그래서 자주 한도에 막히면 올리고, 많이 남으면 내리면 돼요. 저는 Pro부터 시작해서 부족하면 올려보길 추천해요.</p>

<h2>정리하면</h2>

<blockquote>
<p>· 요금제 = 무료 / Pro($20) / Max 5x($100) / Max 20x($200)</p>
<p>· 고급 기능(Opus·Projects·Claude Code·MCP)은 Pro부터</p>
<p>· Pro와 Max는 기능 동일. Max는 '사용량'만 5배·20배</p>
<p>· 한도 = 5시간 + 주간(이중). 코드·웹·데스크톱이 같은 통 공유</p>
<p>· 바이브코딩 = 말로 시켜 프로그램 만들기. Claude Code가 대표</p>
<p>· 선택 = 자주 막히면 올리고, 남으면 내리기 (변경해도 내역 유지)</p>
</blockquote>

<p>AI 구독이 처음이면 Pro로 시작해서 감을 잡는 걸 추천해요. 바이브코딩처럼 재밌는 것도 Pro부터 다 되니까요. 요금·한도는 계속 바뀌니 결제 전엔 공식 페이지 확인 잊지 마시고요.</p>

<p>긴 글 읽어주셔서 감사합니다.</p>
