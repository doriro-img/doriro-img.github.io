```

  tc-*.png (썸네일)  111장 · 평균 502KB · 54MB   ← 아무도 안 불러감
```

**썸네일은 티스토리에 직접 업로드합니다.** 대표이미지는 티스토리가 자기 서버에 올라온
이미지만 후보로 잡기 때문입니다. CDN 의 `tc-*.png` 54MB 는 죽은 파일입니다.

`art/*.html` + `tools/tc_*.json` 이 있으면 `mk-tc.cjs` + `make-art.cjs` 로 언제든 재생성됩니다.
PNG 는 소스가 아니라 빌드 산출물입니다.

### ★ 예외 4장 — 절대 무시하면 안 됨

옛 원고가 **CDN 주소로 직접 참조**합니다. 빼면 발행된 글의 이미지가 깨집니다.

| 슬러그 | 참조하는 원고 |
|---|---|
| `tc-aircon` | `2026-08-12-aircon-electricity.txt` |
| `tc-beolcho` | `2026-08-12-beolcho-guide.txt` |
| `tc-ansangho` | `2026-08-13-ansangho.txt` |
| `tc-charye` | `2026-08-13-charye-table.txt` |

전체 `tc-*` 중 CDN 참조는 **이 4장이 전부**입니다 (재확인 완료).

### 실행

`.gitignore` 에 넣고 예외 4장은 되살립니다.

```gitignore
# 썸네일 PNG 는 티스토리에 직접 업로드하므로 CDN 서빙 대상이 아니다.
# art/*.html + tools/tc_*.json 으로 언제든 재생성된다 (mk-tc.cjs → make-art.cjs).
2026/*/tc-*.png

# 예외 — 옛 원고가 CDN 주소로 직접 부르는 4장
!2026/*/tc-aircon.png
!2026/*/tc-beolcho.png
!2026/*/tc-ansangho.png
!2026/*/tc-charye.png
```

그다음 이미 추적 중인 것을 인덱스에서만 뺍니다 (**로컬 파일은 남겨야 함**).

```bash
git rm --cached 2026/*/tc-*.png
git checkout -- .gitignore   # 위 예외가 살아있는지 확인
git status --porcelain | grep -c '^D '   # 빠진 개수
```

빼기 전후로 **예외 4장이 여전히 추적되는지** 반드시 확인합니다.

```bash
git ls-files 2026/ | grep -E 'tc-(aircon|beolcho|ansangho|charye)\.png'
# 4줄이 나와야 정상
```

## 3단계 — 굽는 크기를 절반으로

`make-art.cjs` 의 `deviceScaleFactor: 2` → `1`.

1600×1600 이 800×800 이 되고 **502KB → 약 130KB** 입니다.
티스토리 목록 썸네일은 300px 남짓이라 800 이면 충분합니다.
로컬 다운로드 폴더가 가벼워지고 티스토리 업로드도 빨라집니다.

바꾼 뒤 한 장 구워서 실제 크기를 확인하고, 발행 보드 미리보기로 화질을 봅니다.

**주의**: 옛 도식(`b02-trend.png` 같은)은 본문 폭 860~1100px 로 들어가므로
2배 스케일이 필요합니다. 도식은 이제 안 만들지만, 만약 만들 일이 생기면
스케일을 되돌리거나 썸네일 전용 옵션을 둡니다.
